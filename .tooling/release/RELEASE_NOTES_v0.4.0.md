# 缝手套记工 v0.4.0

Android 端**离线**计件记工应用，专为手工缝纫手套计件工作设计。
数据只存在手机本机（SharedPreferences 纯文本），**不联网、不申请任何权限**。

- 应用名称：缝手套记工
- 包名：`com.mr5u.glovestatistics`
- 版本：`0.4.0`（versionCode 4）
- 系统要求：Android 8.0 及以上（minSdk 26，targetSdk 37）

---

## 这一版改了什么

### 0. 手套库重名会先提示

同一本手套库里名称是唯一的。以前新建或改名撞到已有名称时会**直接静默替换**，
看起来就像数据被顶掉了。现在会先把后果说清楚，确认之后才动手：

- 输入的名称已存在时输入框标红，并显示库里已有的那条及其默认单价；
- 明确说明保存后会「把默认单价改成新填的价格，并把同名记录并到这一条下面」；
- 按钮从「保存」变成「仍然合并」→ 再点「确认合并并保存」，两步都过了才真正写入；
- 想保留两条同名不同价的手套，提示里会建议把名称改得能区分（比如加尺寸）；
- 修改手套时改成别人的名字，同样会提示两条记录会被合并。

### 1. 厂房工作也能按件记工了

以前的厂房只能填一个「当天收入」数字。现在厂房那栏有**两种记法，随手切换**：

| 模式 | 怎么用 | 收入怎么来 |
| --- | --- | --- |
| **按件计酬**（默认） | 选厂房手套种类 → 自动带出单价 → 填完成数量 | **自动算**：单价 × 数量 |
| **当天总收入** | 直接填一笔金额 | 你填多少就是多少 |

原来的用法一条都没少，以后厂房给的是打包价、临时工，照样用「当天总收入」记。

厂房有自己**独立的手套库**（「手套库」页顶部可切换「⌂ 家里手套 / ▦ 厂房手套」），
因为厂房做的活和家里的往往不是同一批、单价也不一样，分开建库就不会互相串价。

### 2. 同一天的重复记录自动合并

以前同一天记 3 笔「22 公分绿牛」，导出图上就是 3 行。现在**同一天、同一种手套的记录会自动合并**：

```
9 月 23 日   22 公分绿牛   602   0.26   156.52      ← 3 笔合成 1 行
```

- 合并规则：同一天 + 同种类 + 同单价 → 数量相加、收入相加。
- **单价也参与合并判断**：同一天同种类如果记了两个不同单价，会保留两行，绝不硬合并算错钱。
- 厂房整笔记录按「金额 + 备注」合并，备注不同就各自保留（那通常是两件不同的活）。
- 记工页、记录页、本月页、导出的 PNG 全都是合并后的结果，笔数也按合并后算。
- **底层原始记录仍然分开存着，一条都没删**，合并只发生在显示与统计层。

### 3. 导出 PNG 修好了「右边被截断」

老版本导出的图，表格右侧会贴到图片边缘，在聊天软件里预览时看着像被切掉了。
这一版从根上改掉：

- 表格内容右边界内缩 64px，**文字永远不会贴到图片边缘**；
- 合计行改成**显式指定落在哪一列**，顺手修掉了「合计 3 笔」跑到「数量」列下面的错位 bug；
- 任何一格的文字放不下时会先自动缩小字号、再截断加省略号，绝不会越出列边界；
- 图片类型正确声明为 `image/png`，存相册、发微信识别更准。

同时按天重排了报表内容：

| 区块 | 内容 |
| --- | --- |
| ① 每日汇总（按天合并） | 日期 · 手套数量 · 手套收入 · 厂房收入 · 当日合计 |
| ② 家里手套计件明细 | 同一天同种类已合并 |
| ③ 各手套种类汇总 | 数量 · 收入 · 占比 |
| ④ 厂房工作明细 | 日期 · 种类 · 数量 · 单价 · 收入 · 备注 |
| ⑤ 厂房计件汇总 | 按种类合计数量、均价、收入、占比 |
| ⑥ 汇总合计 + 页脚 | 手套收入 / 厂房收入 / 计件数量 / 全部劳动收入 / 工作天数 |

### 4. 升级不会丢数据（这版特别加固了）

先说结论：**直接覆盖安装，数据不会丢，也不用你做任何操作。**

原因和保障：

1. **本来就是覆盖升级**：包名 + 签名不变时，Android 只替换代码，`glove_statistics` 里的数据原样保留。
   本项目一直用 `.tooling/debug.keystore` 签名，只要这个文件和包名不动，升级就是安全的。
2. **存储格式向后兼容**：厂房记录的行格式从 `日期|金额|备注` 扩成 7 个字段，
   解析时**按字段个数判断版本**——老数据一行都不用改就能读出来。
   因此这次升级**没有「整表迁移」这一步**，也就不存在迁移到一半失败的风险。
   写入的新格式老版本也能读（前三个字段含义没变，金额不会算错）。
3. **自动备份**：每次记工后，App 会把一份完整 XML 另存到
   `Android/data/com.mr5u.glovestatistics/files/backup/`（**不需要任何权限**，卸载重装也还在），
   最多保留最近 5 份，自动轮换。
4. **界面里能看见**：「本月」页底部新增「数据安全」区，显示上次自动备份时间，
   可以「立即备份」，也可以直接用某一份自动备份恢复。
5. **升级后会有提示**：更新完第一次打开，会弹一句「已从旧版本继承 N 条数据，没有丢失」，
   不用自己猜。

> 唯一会丢数据的情况还是那两种：**先卸载再安装**，或者换了签名。
> 签名不一致时系统会直接拒绝安装（不会删数据），但如果你因此手动先卸载，数据就没了。

### 5. 顺手加的小东西

- **本月页新增「每日清单」**：一眼看到这个月每天做了多少、挣了多少，不用翻月历。
- **本月页新增「厂房计件种类」**：厂房按件做的活也有种类占比。
- 导出的长图在内容过多时会自动等比缩小，避免高到相册打不开。

## 收入计算规则

| 项目 | 计算方式 | 是否计入手套收入 |
| --- | --- | --- |
| 家里手套 | 单价 × 数量 | 是 |
| 厂房 · 按件计酬 | 单价 × 数量（自动算） | 否，单独统计 |
| 厂房 · 当天总收入 | 你填的金额 | 否，单独统计 |
| 本月全部劳动收入 | 手套收入 + 厂房收入 | —— |

## 各模块作用

### 记工（首页）
先选日期（默认今天，可切换补录过去的日期），再分别录入两类活。

- **家里手套**：选手套种类 → 自动带出单价 → 填数量 → 实时显示预计收入 → 保存。
- **厂房工作**：切换「按件计酬 / 当天总收入」两种模式后录入，可加备注。
- 下方「当天已记」是**合并后**的结果，同一天同种类只显示一行。

### 记录（月历）
一整月的月历，绿点＝在家做手套，橙点＝去了厂房，都没有＝未干活。
点任意一天展开当天明细（已合并），可以修改或删除每条记录。

### 手套库
「⌂ 家里手套」和「▦ 厂房手套」两本独立的库，各自新建 / 改名 / 改价 / 删除；
同一本库里名称唯一，重名会先提示再确认。
记录里保存的是**当天的单价快照**，所以以后调价不会把过去已经算好的收入改掉。

### 本月
收入汇总 + 每日清单 + 手套种类明细 + 厂房计件种类明细 + 导出与备份 + 数据安全。

## 安装说明

下载 `Glove-Statistics-0.4.0-release.apk`，**直接覆盖安装**即可
（需要在系统里允许「安装未知来源应用」）。不要先卸载，卸载会清掉本机数据。

> **关于签名**：本 Release 使用 Android 通用的 **debug 签名**
> （`.tooling/debug.keystore`，密码为公开的 `android`），目的是让
> `assembleRelease` 能直接产出可安装的包，**仅供自用与个人分发，不适合上架应用商店**。
> 现有数据是用这个签名装的，所以升级也必须用同一个签名的包，否则系统会拒绝安装。
