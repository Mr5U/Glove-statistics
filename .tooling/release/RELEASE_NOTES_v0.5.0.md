# 缝手套记工 v0.5.0

Android 端**离线**计件记工应用，专为手工缝纫手套计件工作设计。
数据只存在手机本机（SharedPreferences 纯文本），**不联网、不申请任何权限**。

- 应用名称：缝手套记工
- 包名：`com.mr5u.glovestatistics`
- 版本：`0.5.0`（versionCode 5）
- 系统要求：Android 8.0 及以上（minSdk 26，targetSdk 37）

---

## 这一版改了什么

一句话：**做减法**。把没什么用的「厂房工作」整块去掉，导出的图也精简成一张表。

### 0. 厂房工作整块下线

原来厂房那套记法（按件计酬 / 当天总收入两种模式、厂房独立手套库、月历上的橙色圆点、
厂房收入汇总、厂房计件种类汇总）**全部移除**：

| 位置 | 变化 |
| --- | --- |
| 记工页 | 只剩「家里手套」一栏：选种类 → 自动带出单价 → 填数量 → 保存 |
| 记录页 | 月历上只有绿色圆点（当天在家做手套），厂房记录与橙色圆点没了 |
| 手套库 | 只有一本库，不再有「⌂ 家里手套 / ▦ 厂房手套」切换 |
| 本月页 | 只显示家里手套收入，不再有「厂房工作收入」和「全部劳动收入」 |
| XML 备份 | 只写手套库与手套记录两段，厂房两段不再写出 |

**老数据一条都没有删。** 升级时不做任何搬迁，`SharedPreferences` 里原来的
`factory` / `factoryGloves` 两个键**原样留着**，只是 App 不再读、也不再写：

- 升级过程里没有「整表重写」这一步，也就没有迁移到一半失败的风险；
- 万一以后还要翻这批老账，回装 0.4.0 还能原样读出来。

旧备份文件（v1 / v2）**照样能恢复**：文件里的厂房两段会被直接忽略，
手套库和家里手套记录原样还原。

### 1. 导出的 PNG 只剩「家里手套计件明细」

| 现在图里有什么 | 现在图里没有了 |
| --- | --- |
| 一张「家里手套计件明细」表：日期 · 手套种类 · 数量 · 单价 · 收入（同一天同种类已合并成一行），末尾一行合计（N 笔 / X 双 / ¥金额），再加两行页脚 | ~~各手套种类汇总~~、~~每日汇总~~、~~厂房工作明细~~、~~厂房计件汇总~~、~~收入汇总区~~ |

- 图短了很多，发微信、存相册都更清爽；
- 导出时**不用再选范围**了：原来「只导出手套账单 / 只导出厂房收入 / 导出全部劳动收入」
  三种范围是围着厂房账设计的，现在只有一本账，直接出图；
- 之前修好的排版问题全部保留：表格右边界内缩 64px、合计行显式指定落在哪一列、
  放不下先缩字号再截断加省略号、最后一列离图片边缘留有安全距离。

### 2. 升级不会丢数据

先说结论：**直接覆盖安装，数据不会丢，也不用你做任何操作。**

1. **本来就是覆盖升级**：包名 + 签名不变时，Android 只替换代码，
   `glove_statistics` 里的数据原样保留。本项目一直用 `.tooling/debug.keystore` 签名，
   只要这个文件和包名不动，升级就是安全的。
2. **存储格式向后兼容**：家里手套记录还是 `日期|种类|单价|数量` 这 4 个字段，
   v0.3.0 / v0.4.0 写下的数据一行都不用改就能读出来，这次同样没有整表迁移这一步。
3. **自动备份**：每次记工后，App 会把一份完整 XML 另存到
   `Android/data/com.mr5u.glovestatistics/files/backup/`（**不需要任何权限**，卸载重装也还在），
   最多保留最近 5 份，自动轮换。
4. **界面里能看见**：「本月」页底部「数据安全」区显示上次自动备份时间，
   可以「立即备份」，也可以直接用某一份自动备份恢复。
5. **升级后会有提示**：更新完第一次打开，会弹一句「已从旧版本继承 N 条数据，没有丢失」。

> 唯一会丢数据的情况还是那两种：**先卸载再安装**，或者换了签名。
> 签名不一致时系统会直接拒绝安装（不会删数据），但如果你因此手动先卸载，数据就没了。

## 收入计算规则

| 项目 | 计算方式 |
| --- | --- |
| 家里手套 | 单价 × 数量 |
| 本月合计 | 当月所有记录的收入相加 |

## 各模块作用

### 记工（首页）
先选日期（默认今天，可切换补录过去的日期），再从手套库选种类 →
自动带出单价 → 填完成数量 → 实时显示「单价 × 数量」的预计收入 → 保存。
同一天可以记多笔、多种手套；下方「当天已记」是合并后的结果，同一天同种类只显示一行。

### 记录（月历）
一整月的月历，绿点＝当天在家做手套，一个点都没有＝未干活。
点任意一天展开当天明细（已合并），可以修改或删除每条记录，也支持翻月补录。

### 手套库
一本库：新建 / 改名 / 改价 / 删除。同一本库里名称唯一，重名会先提示再确认。
记录里保存的是**当天的单价快照**，所以以后调价不会把过去已经算好的收入改掉；
删除手套种类也不会删掉历史记录。

### 本月
收入汇总 + 每日清单 + 各手套种类明细 + 导出与备份 + 数据安全。

## 安装说明

下载 `Glove-Statistics-0.5.0-release.apk`，**直接覆盖安装**即可
（需要在系统里允许「安装未知来源应用」）。不要先卸载，卸载会清掉本机数据。

> **关于签名**：本 Release 使用 Android 通用的 **debug 签名**
> （`.tooling/debug.keystore`，密码为公开的 `android`），目的是让
> `assembleRelease` 能直接产出可安装的包，**仅供自用与个人分发，不适合上架应用商店**。
> 现有数据是用这个签名装的，所以升级也必须用同一个签名的包，否则系统会拒绝安装。
