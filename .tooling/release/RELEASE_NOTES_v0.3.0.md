# 缝手套记工 v0.3.0

Android 端**离线**计件记工应用，专为手工缝纫手套计件工作设计。
数据只存在手机本机（SharedPreferences 纯文本），**不联网、不申请任何权限**。

- 应用名称：缝手套记工
- 包名：`com.mr5u.glovestatistics`
- 版本：`0.3.0`（versionCode 3）
- 系统要求：Android 8.0 及以上（minSdk 26，targetSdk 37）

---

## 各模块作用

### 1. 记工（首页）
当天工作的录入入口，**家里手套**与**厂房工作**两本账互相独立。

- 先选日期，默认今天，可切换到过去的日期补录。
- **家里手套**：从手套库选种类 → 自动带出该种类的单价 → 输入数量 →
  实时显示「单价 × 数量」的预计收入 → 保存。同一天可记多笔、多种手套。
- **厂房工作**：录入当天实际收入 + 可选备注。
  **独立成账，不计入手套收入。**
- 同一天既在家做手套、又去厂房干活时，两类记录互不影响。

### 2. 记录（月历）
一整月的月历视图，把「哪天干了什么活」直接标在日期格上。

- 绿色圆点 = 当天在家做手套
- 橙色圆点 = 当天去了厂房
- 两个圆点 = 那天两头都干了
- 没有圆点 = 当天未干活
- 点任意一天展开当天明细，可**修改或删除**每一条手套 / 厂房记录。
- 支持翻到上个月、下个月回看与补录。

### 3. 手套库
手套种类与单价的维护页。

- 新建「手套名称 + 默认单价」，保存在本地，以后记工直接选，不用重复输入。
- 支持改名、改价、删除。
- 记录里存的是**当天的单价快照**，以后调价不会改动过去已算好的收入。
- 删除手套种类不会删除历史记录，历史收入照常统计。

### 4. 本月
收入汇总页，可切换月份查看任意一个月。

- 分别显示**家里手套收入**、**厂房工作收入**，以及两者相加的**全部劳动收入**。
- 显示本月干活天数、手套总数量，以及各手套种类的数量与收入明细（按收入排序）。

### 5. 导出与备份
导出走系统文件选择器（SAF），文件存到手机本地、SD 卡还是网盘由你自己决定，
**不需要申请存储权限**。

- **PNG 统计图**：适合发微信或存相册，可选三种范围：
  - 只导出手套账单
  - 只导出厂房收入
  - 导出全部劳动收入（两张表 + 汇总合计）
- **XML 完整备份**：包含全部手套种类、所有月份的手套记录与厂房记录，适合换手机或长期存档。
- **从 XML 备份恢复**：用备份内容替换当前全部数据（恢复前二次确认）。

## 收入计算规则

| 项目 | 计算方式 | 是否计入手套收入 |
| --- | --- | --- |
| 家里手套 | 单价 × 数量 | 是 |
| 厂房工作 | 当天实际收入 | 否，单独统计 |
| 本月全部劳动收入 | 手套收入 + 厂房收入 | —— |

## 安装说明

下载下方的 `Glove-Statistics-0.3.0-release.apk` 直接用手机安装即可
（需要在系统里允许「安装未知来源应用」）。

> **关于签名**：本 Release 的 APK 使用 Android 通用的 **debug 签名**
> （`.tooling/debug.keystore`，密码为公开的 `android`），目的是让
> `assembleRelease` 能直接产出可安装的包，**仅供自用与个人分发，不适合上架应用商店**。
> 将来需要上架时，把 `app/build.gradle.kts` 里的 `signingConfig`
> 换成自己的正式 keystore 重新打包即可。
