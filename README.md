# 缝手套记工

面向手工缝纫手套计件工作的 Android **离线**统计应用。数据只存在本机，不需要联网，也不需要任何权限。

- 应用名称：缝手套记工
- 包名：`com.mr5u.glovestatistics`
- 当前版本：`0.4.0`
- 系统要求：Android 8.0 及以上

## v0.4.0 更新内容

### 手套库重名会先提示（本次新增）

同一本手套库里名称是唯一的。以前新建或改名撞到已有名称时会**直接静默替换**，看起来就像数据被顶掉了。
现在会先弹出提示，把后果说清楚，确认之后才动手：

- 输入的名称已存在时，输入框标红，并提示库里已有的那条及其默认单价；
- 明确说明保存后会「把默认单价改成新填的价格，并把同名记录并到这一条下面」；
- 按钮从「保存」变成「仍然合并」→ 再点「确认合并并保存」，两步都过了才真正写入；
- 想保留两条同名不同价的手套，提示里会建议把名称改得能区分（比如加尺寸）；
- 修改手套时如果改成别人的名字，同样会提示两本记录会被合并。

### 厂房工作支持选手套种类 + 数量，收入自动算

厂房那栏现在有两种记法，可随手切换：

| 模式 | 怎么用 | 收入怎么来 |
| --- | --- | --- |
| **按件计酬**（默认） | 选厂房手套种类 → 自动带出单价 → 填完成数量 | **自动算**：单价 × 数量 |
| **当天总收入** | 直接填一笔金额 | 你填多少就是多少 |

原来的用法一条都没少，厂房给打包价、临时工照样用「当天总收入」记。
厂房有**独立的手套库**（「手套库」页顶部切换「⌂ 家里手套 / ▦ 厂房手套」），
因为厂房做的活和家里的往往不是同一批、单价也不一样，分开建库就不会互相串价。

### 同一天的重复记录自动合并

同一天记 3 笔「22 公分绿牛」，以前导出图上是 3 行，现在会合并成 1 行：

```
9 月 23 日   22 公分绿牛   602   0.26   156.52      ← 3 笔合成 1 行
```

- 合并规则：同一天 + 同种类 + 同单价 → 数量相加、收入相加。
- **单价也参与合并判断**：同一天同种类如果记了两个不同单价，会保留两行，绝不硬合并算错钱。
- 厂房整笔记录按「金额 + 备注」合并，备注不同就各自保留（那通常是两件不同的活）。
- 记工页、记录页、本月页、导出的 PNG 全是合并后的结果，笔数也按合并后算。
- **底层原始记录仍然分开存着，一条都没删**，合并只发生在显示与统计层。

### 导出 PNG 修好了右边被截断

老版本导出的图，表格右侧贴到图片边缘，在聊天软件里预览时看着像被切掉了。这一版从根上改掉：

- 表格内容右边界内缩 64px，**文字永远不会贴到图片边缘**；
- 合计行改成**显式指定落在哪一列**，顺手修掉了「合计 3 笔」跑到「数量」列下面的错位问题；
- 任何一格文字放不下时会先自动缩小字号、再截断加省略号，绝不会越出列边界；
- 图片类型正确声明为 `image/png`，存相册、发微信识别更准。

同时按天重排了报表内容：

| 区块 | 内容 |
| --- | --- |
| ① 每日汇总（按天合并） | 日期 · 手套数量 · 手套收入 · 厂房收入 · 当日合计 |
| ② 家里手套计件明细 | 同一天同种类已合并 |
| ③ 各手套种类汇总 | 数量 · 收入 · 占比 |
| ④ 厂房工作明细 | 日期 · 种类 · 数量 · 单价 · 收入 · 备注 |
| ⑤ 厂房计件汇总 | 按种类合计数量、均价、收入、占比 |
| ⑥ 汇总合计 + 页脚 | 手套收入 / 厂房收入 / 计件数量 / 全部劳动收入 / 工作天数 |

### 升级不会丢数据

**直接覆盖安装即可，不用做任何额外操作。**

1. 包名与签名不变时，Android 只替换代码，本机数据原样保留。本项目一直用同一份 debug keystore，
   只要这个 keystore 文件和包名不动，升级就是安全的。
2. **存储格式向后兼容**：厂房记录的行格式扩展后，解析时按字段个数判断版本，
   老数据一行都不用改就能读出来。这次升级**没有整表迁移这一步**，也就没有迁移失败的风险。
3. **自动备份**：每次记工后，App 会把一份完整 XML 另存到
   `Android/data/com.mr5u.glovestatistics/files/backup/`（**不需要任何权限**，卸载重装也还在），
   最多保留最近 5 份，自动轮换。
4. **界面里能看见**：「本月」页底部新增「数据安全」区，显示上次自动备份时间，
   可以「立即备份」，也可以直接用某一份自动备份恢复。
5. **升级后有提示**：更新完第一次打开会提示「已从旧版本继承 N 条数据，没有丢失」。

> 唯一会丢数据的情况：**先卸载再安装**，或者换了签名（系统会直接拒绝安装，若因此手动卸载数据就没了）。

### 顺手加的小东西

- **本月页新增「每日清单」**：一眼看到这个月每天做了多少、挣了多少。
- **本月页新增「厂房计件种类」**：厂房按件做的活也有种类占比。
- 导出的长图在内容过多时会自动等比缩小，避免高到相册打不开。

## 功能说明

### 记工（首页）
- 先选日期（默认今天，可切换补录过去的日期）。
- **家里手套**：从手套库选种类 → 单价自动带出 → 输入数量 → 实时显示「单价 × 数量」的预计收入 → 保存。
  同一天可以记多笔、多种手套。
- **厂房工作**：按件计酬或当天总收入，两种模式随手切换。厂房账**独立成账，不计入手套收入**。
- 下方「当天已记」是合并后的结果：同一天同一种手套只显示一行。

### 记录（月历）
- 一整月的月历，把「干了什么活」直接标在日期上：
  - 绿色圆点 = 当天在家做手套
  - 橙色圆点 = 当天去了厂房
  - 两个都有 = 那天两头都干了
  - **没有圆点 = 未干活**
- 点任意一天展开当天明细（已按种类合并），可以**修改或删除**每一条手套记录 / 厂房记录。
- 支持翻到上个月、下个月回看与补录。

### 手套库
- 两本**互相独立**的库：「⌂ 家里手套」与「▦ 厂房手套」，各自新建 / 改名 / 改价 / 删除。
- 同一本库里名称唯一，重名会先提示（见上）。
- 记录里保存的是**当天的单价快照**，所以以后调价不会把过去已经算好的收入改掉。
- 删除手套种类不会删掉历史记录，历史收入照常统计。

### 本月
- 分别显示**家里手套收入**与**厂房工作收入**，以及两者相加的**全部劳动收入**。
- **每日清单**：按天列出当天的数量、手套收入、厂房收入与当日合计。
- 显示本月干活天数、手套总数量、各手套种类的数量与收入明细（按收入排序），
  以及厂房计件种类明细（数量 / 均价 / 收入）。
- 可切换月份查看任意一个月，底部是「数据安全」区。

### 导出与备份
导出会打开系统文件选择器（SAF），文件由你自己决定存到手机本地、SD 卡还是网盘，**不需要申请存储权限**。

- **PNG 统计图**（`image/png`）：适合发微信或存相册。可选三种范围：
  只导出手套账单 / 只导出厂房收入 / 导出全部劳动收入。
- **XML 完整备份**：包含全部手套种类（含厂房手套库）、所有月份的手套记录与厂房记录，
  适合换手机或长期存档。**v0.3.0 导出的老备份文件仍可直接恢复。**
- **从 XML 备份恢复**：会用备份内容替换当前全部数据（恢复前会二次确认）。

## 收入计算规则

| 项目 | 计算方式 | 是否计入手套收入 |
| --- | --- | --- |
| 家里手套 | 单价 × 数量 | 是 |
| 厂房 · 按件计酬 | 单价 × 数量（自动算） | 否，单独统计 |
| 厂房 · 当天总收入 | 你填的金额 | 否，单独统计 |
| 本月全部劳动收入 | 手套收入 + 厂房收入 | —— |

## 安装

下载 `Glove-Statistics-0.4.0-release.apk`，**直接覆盖安装**即可
（需要在系统里允许「安装未知来源应用」）。**不要先卸载**，卸载会清掉本机数据。

> 本应用目前使用 Android 通用的 debug 签名，仅供自用与个人分发，不适合上架应用商店。
> 升级时务必使用同一签名的安装包，否则系统会拒绝覆盖安装。
