# 缝手套记工

面向手工缝纫手套计件工作的 Android **离线**统计应用。数据只存在本机，不需要联网，也不需要任何权限。

- 应用名称：缝手套记工
- 包名：`com.mr5u.glovestatistics`
- 当前版本：`0.5.0`
- 系统要求：Android 8.0 及以上

## v0.5.0 更新内容

这一版是**做减法**：把没什么用的「厂房工作」整块去掉，导出图也精简成一张表。

### 厂房工作整块下线

原来厂房那套记法（按件计酬 / 当天总收入、独立手套库、橙色圆点、厂房收入汇总）全部移除：

| 位置 | 变化 |
| --- | --- |
| 记工页 | 只剩「家里手套」一栏，选种类 → 单价自动带出 → 填数量 → 保存 |
| 记录页 | 月历上只有绿色圆点（当天做了手套），厂房记录与橙色圆点没了 |
| 手套库 | 只有一本库，不再有「⌂ 家里手套 / ▦ 厂房手套」切换 |
| 本月页 | 只显示家里手套收入，不再有「厂房工作收入」和「全部劳动收入」 |
| XML 备份 | 只写手套库与手套记录两段 |

**老数据一条都没有删。** 升级时不做任何搬迁，`SharedPreferences` 里原来的
`factory` / `factoryGloves` 两个键**原样留着**，只是 App 不再读也不再写：
升级过程里没有「整表重写」这一步，也就没有迁移失败的风险；万一以后要翻这批老账，
回装 0.4.0 还能原样读出来。

旧备份文件（v1 / v2）照样能恢复：文件里的厂房两段会被直接忽略，
手套库和家里手套记录会原样还原。

### 导出的 PNG 只剩「家里手套计件明细」

| 现在图里有什么 | 现在图里没有了 |
| --- | --- |
| 一张「家里手套计件明细」表：日期 · 手套种类 · 数量 · 单价 · 收入（同一天同种类已合并成一行），末尾一行合计（N 笔 / X 双 / ¥金额）；再加一行页脚 | ~~各手套种类汇总~~、~~每日汇总~~、~~厂房工作明细~~、~~厂房计件汇总~~、~~收入汇总区~~ |

- 导出的图短了很多，发微信、存相册都更清爽。
- 导出时**不用再选范围**了：原来「只导出手套账单 / 只导出厂房收入 / 导出全部劳动收入」三种范围是围着厂房账设计的，现在只有一本账。
- 之前修好的排版问题（表格右边界内缩 64px、合计行显式指定落在哪一列、
  放不下先缩字号再截断加省略号）全部保留。

### 升级不会丢数据

**直接覆盖安装即可，不用做任何额外操作。**

1. 包名与签名不变时，Android 只替换代码，本机数据原样保留。本项目一直用同一份 debug keystore，
   只要这个 keystore 文件和包名不动，升级就是安全的。
2. **存储格式向后兼容**：家里手套记录还是 `日期|种类|单价|数量` 这 4 个字段，
   v0.3.0 / v0.4.0 写下的数据一行都不用改就能读出来。
3. **自动备份**：每次记工后，App 会把一份完整 XML 另存到
   `Android/data/com.mr5u.glovestatistics/files/backup/`（**不需要任何权限**，卸载重装也还在），
   最多保留最近 5 份，自动轮换。
4. **界面里能看见**：「本月」页底部「数据安全」区显示上次自动备份时间，
   可以「立即备份」，也可以直接用某一份自动备份恢复。
5. **升级后有提示**：更新完第一次打开会提示「已从旧版本继承 N 条数据，没有丢失」。

> 唯一会丢数据的情况：**先卸载再安装**，或者换了签名（系统会直接拒绝安装，若因此手动卸载数据就没了）。

## 功能说明

### 记工（首页）
- 先选日期（默认今天，可切换补录过去的日期）。
- **家里手套**：从手套库选种类 → 单价自动带出 → 输入数量 → 实时显示「单价 × 数量」的预计收入 → 保存。
  同一天可以记多笔、多种手套。
- 下方「当天已记」是合并后的结果：同一天同一种手套只显示一行。

### 记录（月历）
- 一整月的月历，把「干了什么活」直接标在日期上：
  - 绿色圆点 = 当天在家做手套
  - **没有圆点 = 未干活**
- 点任意一天展开当天明细（已按种类合并），可以**修改或删除**每一条记录。
- 支持翻到上个月、下个月回看与补录。

### 手套库
- 一本库：新建 / 改名 / 改价 / 删除。
- 库里名称唯一，重名会先弹提示（说清「会把默认单价改成新价，并把同名记录并到这一条下面」，
  点「仍然合并」才动手）。
- 记录里保存的是**当天的单价快照**，所以以后调价不会把过去已经算好的收入改掉。
- 删除手套种类不会删掉历史记录，历史收入照常统计。

### 本月
- 显示家里手套收入、本月干活天数。
- **每日清单**：按天列出当天的笔数、数量与收入。
- 显示本月手套总数量、各手套种类的数量与收入明细（按收入排序）。
- 可切换月份查看任意一个月，底部是「数据安全」区。

### 导出与备份
导出会打开系统文件选择器（SAF），文件由你自己决定存到手机本地、SD 卡还是网盘，**不需要申请存储权限**。

- **PNG 统计图**（`image/png`）：只有「家里手套计件明细」一张表，适合发微信或存相册。
- **XML 完整备份**：包含全部手套种类与所有月份的手套记录，
  适合换手机或长期存档。**v0.3.0 / v0.4.0 导出的老备份文件仍可直接恢复**
  （文件里的厂房两段会被忽略）。
- **从 XML 备份恢复**：会用备份内容替换当前全部数据（恢复前会二次确认）。

## 收入计算规则

| 项目 | 计算方式 |
| --- | --- |
| 家里手套 | 单价 × 数量 |
| 本月合计 | 当月所有记录的收入相加 |

## 安装

下载 `Glove-Statistics-0.5.0-release.apk`，**直接覆盖安装**即可
（需要在系统里允许「安装未知来源应用」）。**不要先卸载**，卸载会清掉本机数据。

> 本应用目前使用 Android 通用的 debug 签名，仅供自用与个人分发，不适合上架应用商店。
> 升级时务必使用同一签名的安装包，否则系统会拒绝覆盖安装。
